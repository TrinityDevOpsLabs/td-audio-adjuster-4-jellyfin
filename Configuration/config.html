The Adjust Audio button on movie pages requires an active JavaScript Injector and an enabled script. You can still adjust movies from this page. JavaScript Injector setup
Set up the Adjust Audio button on movie pages
  1. Install JavaScript Injector and restart Jellyfin.
  2. Open Dashboard → Plugins → JavaScript Injector and add a script named AudioAdjuster4Jellyfin.
  3. Set Script URL to /AudioAdjuster/movie-button.js. Include your Jellyfin base path if you use one, for example /jellyfin/AudioAdjuster/movie-button.js.
  4. Enable the script, save, and reload Jellyfin Web. Open a movie as an administrator to see Adjust Audio.

Movie sound settings
These settings apply to the first audio track. Choose a percentage or a fixed amount to make it quieter, or use a target to make quiet movies louder and loud movies quieter.
For example, 80% keeps four-fifths of the original audio level. Choose 50% to 90%.
Choose −6 to −1 decibels. −6 turns the sound down more than −1. The default is −2.
LUFS measures how loud the audio sounds overall. Choose −30 (quieter) to −14 (louder). The default is −23. A quiet track can get louder to reach your target.
Replace the first track to use the adjusted sound by default. Add a track to choose between the original and adjusted sound in Jellyfin’s audio menu.
Keep a full copy so you can restore the original movie later. This takes extra disk space. If a backup exists, new adjustments start from that copy.

Discord notifications
Paste the webhook URL from the Discord channel where you want submission, completion, and error notifications.
Verbose adds loudness and gain details to the Jellyfin server log. Debug also adds track selection, processing times, and FFmpeg exit codes. Debug can make server logs noisy, increase disk usage, and expose media details when logs are shared. Return to Info after troubleshooting.

Adjust a movie

Choose a movie to apply your saved sound settings. Once the adjustment finishes, the updated sound is available for future playback.

Type at least 3 characters of a title, or paste a Jellyfin movie link or item ID.
